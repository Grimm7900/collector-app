> # Creature Collector Project
>
> I have made a creature collector to use for adding, changing,  
> or sorting creatures for catching and soon battling
> 

# Features

- `Add` - Adds creature to list
- `Sort` - Sort PC for creatures 
- `randomCreature` - creates a random creature and give it random stats per encounter
- `moveToParty` - moves creature from pc to party
- `moveToPC` - move creature from party to pc
